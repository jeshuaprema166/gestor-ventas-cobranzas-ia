# Gestor de Ventas y Cobranzas con IA 💳

Aplicación web ligera (Single Page Application) diseñada para administrar ventas a crédito, control de cuotas y cobranza en entornos de alta volatilidad cambiaria.

## Características Principales
- **Multimoneda:** Registro en Dólares (USD), Bolívares (VES) y Pesos (COP), calculando toda la deuda matriz en USD para proteger el capital.
- **Cuotas Flexibles:** Generación de cronogramas semanales, quincenales, mensuales o personalizados.
- **Abonos en Cascada:** Aplicación automática de pagos a la cuota más antigua pendiente (FIFO).
- **Alertas de Vencimiento:** Indicador automático ⛳ para clientes en mora con cálculo de días de retraso.
- **Cobranza y Reportes:** Panel de recuperación de capital mensual, exportación a CSV (Excel) y generación de PDF ejecutivo.
- **Respaldo Seguro:** Exportación e importación de base de datos en formato JSON.

## Tecnología
- HTML5 / CSS3 / JavaScript (Vanilla)
- Persistencia local mediante `localStorage`
- Diseño responsivo con modo oscuro/claro
